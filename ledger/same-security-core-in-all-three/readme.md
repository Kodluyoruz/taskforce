# Same security core in all three

**Why this matters:** Choosing a signer is not like choosing a SaaS plan. The security column does not change with the price.

Developers read pricing tables with one reflex: the expensive tier has the important features. Drop that reflex here, because inside the touchscreen trio, **security is not a paid upgrade**.

All three devices carry the same CC EAL6 certified Secure Element class, run the same Ledger OS, and support the same signing features:

- **Clear Signing**, which shows what a transaction really does in readable language
- **Transaction Check**, an optional pre-signing risk screen for EVM transactions (Ethereum and compatible networks)

You will practice both in Module 5. No touchscreen signer locks either behind a higher price.

So what does more money buy? **Comfort**: a larger or sharper screen, wireless charging, nicer materials. These are real, and they are not trivial, because a screen you like makes reading every transaction less annoying — and you should read every transaction. But they are not security. The $179 Nano Gen5 signs with the same protection as the premium Stax; the cheapest touchscreen signer and the most expensive one sit behind the same boundary.

When you choose among the three, you are choosing screen comfort, size, and budget. You are not choosing a security level.

> **Key idea:** All three touchscreen signers share the same security core. Pay more for comfort, never for protection.
