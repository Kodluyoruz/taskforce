# Keys, seeds, and the Secure Element

> **Lesson 0 — Module overview**

**Key Takeaway:** One master secret creates every key you own. This module shows how, and how a dedicated chip signs with that secret without ever exposing it.

**Goal:** You can explain what a seed phrase really is, how one seed becomes many keys, and how the Secure Element signs a transaction without the private key ever leaving the chip.
