# Agents propose, humans approve

Turn the motto into architecture. Split any agent system into three parts:

- **The proposer** — the agent side, which reads data, drafts actions, and explains its reasoning, and holds no secrets that can move value.
- **The approver** — a human with a hardware signer, through whom every action that spends funds, grants an approval, or changes a rule must pass.
- **The record** — a log of every proposal, approved or rejected, so that when something looks wrong later you can see exactly what the agent asked for.

You already run this architecture every day. CI builds, tests, and stages on its own, and the deploy to production waits for a human approval step. **Treat money the way you treat production.**

Remember where this course began. The signing boundary was never about distrusting yourself; it is about refusing to trust any single machine with your keys, and an AI agent is just another machine: a clever one, a useful one, and still a machine. Every incident file in this course, from a poisoned npm package to a $1.4 billion multisig theft, came down to a machine that was trusted with something only a verified human decision should control.
